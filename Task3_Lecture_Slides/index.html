What is Artificial Intelligence?

The Microwave Example

A regular microwave: you manually set timer based on food type.

An AI microwave: measures temperature, decides cooking time, adjusts without human input.

AI = Software trained on large datasets to make decisions without being explicitly programmed for every scenario.

AI in Daily Life

  • Google Translate — language translation using AI
  • Recommendation Systems — product suggestions, YouTube recommendations
  • Auto-Correction — spell check and grammar prediction
  • ChatGPT / Claude / Gemini — conversational AI assistants

AI is not magic — it's pattern matching on massive datasets.

Three Levels of AI

Level 1 — Predictive AI

Classification: Yes/No, Spam/Not Spam, Cat/Dog

Example: Email spam filter, image recognition

Level 2 — Generative AI

Creates new content: text, images, code, video

Example: ChatGPT, DALL-E, Sora

Level 3 — Agentic AI

End-to-end execution: plans, researches, builds, tests, fixes

Example: AI agents that build landing pages independently

Level 1: Predictive AI

  • Dominant until 2022
  • Also known as Machine Learning (ML)
  • Input → Yes/No classification
  • No conversation, no follow-up questions
  • Examples: Spam detection, fraud detection, weather forecasting

"Give it a cat image, it tells you Yes/No. That's it." — Ammar Aamir

Level 2: Generative AI

  • Emerged with ChatGPT (late 2022)
  • Generates new content from training data patterns
  • Capabilities: text, images, code, video (Sora), audio
  • Conversational — remembers context, can refine outputs

Limitation: Works as a tool — provides one step, human does the rest

Level 3: Agentic AI

Four key capabilities that make AI agentic:

CapabilityDescription
PlanningBreaks big goal into smaller steps with ordering
ResearchSurf the web, gather latest information
Tool UseConnect to external APIs, databases, browsers
Self-CorrectionTest output, find bugs, fix them, iterate until complete

Agentic AI in Action

Building a Landing Page

  1. Goal: "Create a landing page for my new VIP product"
  2. Plan: Research current trends → Choose theme → Build → Test → Fix → Deploy
  3. Research: Browse web for 2026 landing page trends
  4. Build: Generate HTML/CSS code
  5. Test: Check if it works, fix issues
  6. Deliver: Final URL + description

Generative AI vs Agentic AI

DimensionGenerative AIAgentic AI
RoleToolWorker

PlanningNo planningPlans before acting
Self-CorrectionNoYes — iterates until goal met
Human EffortHuman does everything elseHuman supervises, reviews

From Smart Tools to Smart Workers

AI as Tool

Like a drill machine — you still do all the work, the tool just helps one step

"You operate the machine all day. You get tired. You decide."

AI as Worker

Like hiring a contractor — you give requirements, they deliver the final product

"You sip coffee. The worker builds."

Factory Analogy

Without AI

  • Farmer works manually in fields
  • Machines help but need operators
  • Every step requires human presence

With AI Worker

  • Give intent/goal
  • AI plans, researches, builds
  • Human reviews and approves

We've moved from "AI as a Tool" to "AI as a Worker"

Agent Factory

Just as a garment factory produces shirts, the Agent Factory produces AI Workers.

🧠 Design

Define the worker's job, skills, and behavior

🎓 Train

Provide instructions, examples, and rules

🚀 Ship

Deploy to production environment

✅ Verify

Monitor, collect feedback, iterate
