# VintagePhotoLab

Colorize old photos & apply artistic filters, super-resolution, and face restoration.

## Features
- **Colorize (DeOldify)** — Neural network colorization of grayscale/old photos
- **20+ Artistic Filters** — Monochrome, Sepia, Film, Canny, Pencil Sketch, Cartoon, Oil Painting, etc.
- **Super Resolution (4x)** — Real-ESRGAN upscaling
- **Face Restoration** — GFPGAN face enhancement
